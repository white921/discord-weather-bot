# おすすめ服装機能 — 条件と表示テキスト一覧

出典: `src/weather/formatter.ts` の `buildOutfitSuggestion()` / `clothingByTemp()`
対象日: その日(today)の予報。`pickOutfitDayIndex()` が選んだ日のデータを使用。

参照する値:
- `tmax` = 最高気温, `tmin` = 最低気温
- `code` = 天気コード(WMO)
- `pop` = 最大降水確率(%)
- `wind` = 最大風速(m/s)
- `humidity` = 最大相対湿度(%)
- `uv` = 最大UVインデックス

---

## 1. メイン服装アドバイス（最高気温で1つだけ選択）

`clothingByTemp(tmax)` — 上から順に最初に合致した1つ。先頭に `・` を付けて表示。

| 条件 (最高気温 tmax) | 表示テキスト |
|---|---|
| 30°C 以上 | 半袖・通気性のよい素材で。 |
| 26°C 以上 30°C 未満 | 半袖一枚で快適。 |
| 22°C 以上 26°C 未満 | 長袖シャツ、または半袖＋薄手の羽織もの。 |
| 18°C 以上 22°C 未満 | 長袖＋薄手のカーディガン/ジャケット。 |
| 14°C 以上 18°C 未満 | ジャケットや薄手のニット。 |
| 10°C 以上 14°C 未満 | コートまたは厚手のアウター。 |
| 6°C 以上 10°C 未満 | 冬物コート＋マフラーで防寒。 |
| 6°C 未満 | ダウン＋手袋・耳あてでしっかり防寒。 |

---

## 2. 追加アドバイス（条件に合致したものを上から順に追記）

各行は先頭に `・` を付けて、合致したものをすべて表示。

### 寒暖差
| 条件 | 表示テキスト |
|---|---|
| `tmax - tmin >= 8` | 朝晩との寒暖差が大きいので、脱ぎ着しやすい重ね着を。 |

### 天気（雪 → 雷雨 → 雨/高降水確率 のいずれか1つ。上が優先）
| 条件 | 表示テキスト |
|---|---|
| 雪コード(71,73,75,85,86) | 雪予報。滑りにくい靴・防水アウターで。路面凍結に注意。 |
| 雷コード(95,96,99) | 雷雨の恐れ。屋外活動は控えめに、雨具を備えて。 |
| 雨コード(51,53,55,61,63,65,80,81,82) または `pop >= 50` | 降水確率 {pop}%。傘または撥水アウターを。 |

### 冷え込み
| 条件 | 表示テキスト |
|---|---|
| `tmin <= 0` かつ 雪コードでない | 朝の冷え込み厳しめ。路面凍結の可能性に注意。 |

### 風（強風 → 風強め のいずれか1つ。上が優先）
| 条件 | 表示テキスト |
|---|---|
| `wind >= 10` | 強風 (最大 {wind} m/s)。傘破損や自転車に注意。 |
| `wind >= 7` かつ 10 未満 | 風が強め (最大 {wind} m/s)。帽子の飛ばされに注意。 |

### 熱中症
| 条件 | 表示テキスト |
|---|---|
| `tmax >= 30` または (`tmax >= 28` かつ `humidity >= 70`) | 熱中症注意。こまめな水分補給と日陰の利用を。 |

### 紫外線（非常に強い → 強め のいずれか1つ。上が優先）
| 条件 | 表示テキスト |
|---|---|
| `uv >= 8` | 紫外線が非常に強い。日焼け止め・帽子・サングラスを。 |
| `uv >= 6` かつ `tmax >= 25`（uv 8 未満） | 紫外線強め。日焼け対策を。 |

## 3. メッセージ全体のレイアウト

```
## 👕 {日付} のおすすめ服装 — {地域名}

{天気絵文字} {天気ラベル}  /  最高 **{tmax}°C** / 最低 **{tmin}°C**  /  ☔ {pop}%  /  💨 {wind} m/s

・{メイン服装アドバイス}
・{追加アドバイス1}
・{追加アドバイス2}
…

-# ※ 体感には個人差があります。寒がりな方は1段階厚めを目安に。
```

- 地域名 `{title}`: 都道府県名と地域名が同じなら地域名のみ、異なれば「{都道府県名} {地域名}」。
- 最終行(`-#` 始まり)は Discord の小さい注記表示。
